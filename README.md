# Tutorials Repository

This repository stores tutorials created by Claude on various subjects.

## Organization Guidelines

### File Structure
- Each tutorial is saved as a **markdown (.md) file** with a **meaningful, descriptive name**
- Tutorial subjects can cover any topic
- Related files (tutorials on similar topics or with dependencies) are grouped in **folders with meaningful names**

### Naming Conventions
- Use clear, descriptive names that reflect the tutorial content
- Examples:
  - `python-basics.md`
  - `react-hooks-guide.md`
  - `docker-compose-tutorial.md`

### Folder Organization
- Group related tutorials together
- Examples:
  ```
  python/
    ├── python-basics.md
    ├── advanced-decorators.md
    └── async-programming.md

  web-development/
    ├── react-hooks-guide.md
    ├── css-flexbox.md
    └── responsive-design.md
  ```

### Physics (`physics/`)
- **[Einstein's Revolutionary Ideas Explained](physics/einstein-ideas-explained.md)** - Detailed but accessible guide to Einstein's four major breakthroughs, explained without overwhelming mathematics. Covers Special Relativity (time dilation, length contraction, why nothing can exceed light speed, spacetime as unified entity), E=mc² (mass-energy equivalence and why tiny mass contains enormous energy), General Relativity (gravity as curved spacetime, black holes, gravitational waves, expanding universe), and the Photoelectric Effect (light as particles, launching quantum mechanics). Explains using thought experiments Einstein himself used: chasing light beams, falling elevators, twin paradox. Includes real-world applications (GPS, nuclear energy, particle physics), what Einstein got wrong (rejecting quantum mechanics, cosmological constant), and why these ideas matter today. Makes mind-bending concepts understandable through analogies, examples, and clear explanations. Perfect for understanding how Einstein changed our view of space, time, energy, and reality itself.
