# Tutorials Repository

This repository stores tutorials created by Claude on various subjects.

## Organization Guidelines

### File Structure
- Each tutorial is saved as a **markdown (.md) file** with a **meaningful, descriptive name**
- Tutorial subjects can cover any topic
- Related files (tutorials on similar topics or with dependencies) are grouped in **folders with meaningful names**

### Naming Conventions
- Use clear, descriptive names that reflect the tutorial content
- Examples:
  - `python-basics.md`
  - `react-hooks-guide.md`
  - `docker-compose-tutorial.md`

### Folder Organization
- Group related tutorials together
- Examples:
  ```
  python/
    ├── python-basics.md
    ├── advanced-decorators.md
    └── async-programming.md

  web-development/
    ├── react-hooks-guide.md
    ├── css-flexbox.md
    └── responsive-design.md
  ```
